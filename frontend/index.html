Historical input

Bundled labeled trade chunks are the replay source. The app does not subscribe to an exchange.

data/pump_dump_dataset/labeled_trades.csv
02

Chronological replay

Timestamp-ordered rows enter a local queue at the selected playback multiplier.

backend/spark/src/ingestion.py
03

Feature engineering

Rolling market history produces the model’s 12 serving-time features for each 5-second chunk.

backend/spark/src/preprocessing.py
04

Model inference

The saved scaler and XGBoost model produce a raw score; scores at or above 0.50 are flagged.

backend/spark/src/anomaly_detection.py · models/
05

Episode grouping

Flagged chunks sharing a benchmark event ID are grouped for review. A flag is a prediction, not proof.

ALERT_EPISODES · process memory
06

Relationship graph

MarketEvent, CryptoAsset and available PumpGroup records are linked in an in-memory graph; no wallet data exists.

backend/spark/src/graph_builder.py
07

Dashboard delivery

Flask endpoints deliver the current replay, graph and stored benchmark metrics to these seven views.

backend/api/app.py · frontend/index.html
